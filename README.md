# Python Basics

A beginner-friendly Jupyter Notebook covering the core concepts needed to start programming with Python. The notebook combines concise explanations with runnable examples and practice exercises.

## Contents

The [`python_fundamentals.ipynb`](./python_fundamentals.ipynb) notebook covers:

- Variables and common data types
- User input and type casting
- String operations and methods
- Arithmetic, assignment, comparison, and logical operators
- Operator precedence
- Conditional statements with `if`, `elif`, and `else`
- `for` and `while` loops
- The `range()` function
- `break` and `continue`
- Lists, tuples, sets, and dictionaries
- Defining and using functions

## Getting Started

### Prerequisites

- Python 3.8 or later
- Jupyter Notebook or JupyterLab

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/bhargavasugam08/python_basics.git
   cd python_basics
   ```

2. Install Jupyter Notebook if it is not already installed:

   ```bash
   python -m pip install notebook
   ```

   Alternatively, install JupyterLab:

   ```bash
   python -m pip install jupyterlab
   ```

### Run the Notebook

Start Jupyter Notebook:

```bash
jupyter notebook
```

Or start JupyterLab:

```bash
jupyter lab
```

Open `python_fundamentals.ipynb` in the browser and run the cells from top to bottom.

## Notebook Notes

- The examples are designed for learners who are new to Python.
- Some interactive `input()` examples use sample values so that the notebook can run without pausing for input. You can uncomment the original `input()` statements to experiment with your own values.
- Run each code cell in order to reproduce the displayed outputs.

## Learning Goals

After completing the notebook, you should be able to:

- Store and work with values using variables and built-in data types.
- Convert values between common Python types.
- Manipulate strings and use common string methods.
- Write expressions using Python operators.
- Make decisions with conditional statements.
- Repeat tasks using loops and control loop execution.
- Choose appropriate built-in data structures for simple problems.
- Organize reusable logic into functions.
